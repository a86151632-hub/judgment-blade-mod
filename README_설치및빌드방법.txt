  ✦ 단죄의 성검 (Judgment Blade) Fabric 1.21.4 모드 빌드 가이드 ✦
  - 내 컴퓨터에 Java 설치 없이 GitHub에서 .jar 자동 생성하기 -
====================================================================

[1단계] GitHub에 새 저장소 만들기
 1. GitHub(https://github.com/a86151632-hub)에 로그인합니다.
 2. 우측 상단 '+' -> 'New repository' 클릭 후 이름을 'judgment-blade-mod'로 생성합니다.

[2단계] 압축 푼 파일들을 GitHub에 업로드하기
 1. 이 ZIP 파일의 압축을 풉니다.
 2. 생성한 GitHub 저장소 화면에서 'uploading an existing file'을 누르거나,
    소스트리(Sourcetree)로 이 폴더를 연결해 모든 파일을 Push합니다.
    (주의: 숨김 폴더인 '.github' 폴더도 반드시 함께 올라가야 합니다!)

[3단계] 깃허브가 자동으로 구워준 .jar 파일 다운로드하기!
 1. GitHub 저장소 상단 메뉴의 [Actions] 탭을 클릭합니다.
 2. 'Build Fabric Mod (.jar)' 워크플로우가 자동으로 돌아가며 초록색 체크(✓)가 뜹니다 (약 1~2분 소요).
 3. 완료된 항목을 클릭하고 맨 아래 'Artifacts' 항목에 있는
    [JudgmentBlade-Mod-1.21.4-JAR]를 클릭하면 완성된 .jar 파일이 다운로드됩니다!

[4단계] 마인크래프트 적용 및 인게임 확인
 1. 다운로드한 .jar 파일을 마인크래프트 1.21.4 (Fabric 로더 설치 필요)의 'mods' 폴더에 넣습니다.
 2. 게임 접속 후 크리에이티브 인벤토리 -> [전투(Combat)] 탭 맨 아래를 보면
    '✦ 단죄의 성검 (Judgment Blade) ✦'이 전용 아이템으로 등록되어 있습니다!
